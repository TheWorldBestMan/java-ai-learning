# 同步准备

此目录是数据库配置草案，尚未连接 Supabase 项目，也尚未启用网站自动同步。请勿将 secret 或 service_role 密钥放在网站或公开仓库中。

项目创建后，需要配置邮箱登录、运行并验证 setup.sql、确认 Data API 对 authenticated 角色开放、配置 RLS，并使用两个不同用户验证隔离。需配套实现和验证客户端的会话、离线队列、修订号冲突检测及草稿冲突处理后，才能启用自动同步。项目 URL 和 publishable key 可以公开，但必须配合正确的 RLS。

本 SQL 使用 create policy，重复执行前需检查已有策略；不要在已有项目盲目重复运行。创建数据库表属于外部数据变更，部署前应在目标项目核对。
